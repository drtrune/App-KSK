# Antigravity Agent Skills

## Active Commands
- `/spec` -> Kích hoạt Browser Agent tìm kiếm công nghệ + Viết tài liệu đặc tả hệ thống.
- `/plan` -> Lập lộ trình thiết kế/code theo từng bước chi tiết, chờ user duyệt.
- `/build` -> Thực hiện viết code hoặc cấu hình hệ thống theo kế hoạch.
- `/test` -> Tự động chạy thử, debug và tối ưu hóa mã nguồn.

## System Constraints
- Luôn kiểm tra cấu trúc thư mục hiện tại trước khi tạo file mới.
- Tối ưu hóa token: Trả lời ngắn gọn, tập trung vào code, không giải thích dông dài.
